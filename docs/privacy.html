Privacy Policy

Last updated: 20 November 2026.

MahaSpark is a personal tool used by one person (the channel owner) to upload that person's own videos to the owner's own YouTube channel.

What we access

When the owner signs in with Google, the tool receives permission to upload videos (https://www.googleapis.com/auth/youtube.upload) to the owner's channel. It does not read your personal data, and it does not access anyone else's account.

What we store

The authorisation (refresh token) is kept only in the owner's private GitHub Actions secrets and local settings file. It is never published, sold or shared.

Visitors and viewers

This site collects no personal information, sets no cookies and has no user accounts.

Google API Services

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
