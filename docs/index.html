MahaSpark News

MahaSpark is a Marathi news and knowledge channel (YouTube: @MahaSparkOfficial). This site belongs to the open-source tool that prepares and uploads the channel's own videos to the channel owner's own YouTube account.

The tool uses the YouTube Data API only to upload videos (scope youtube.upload) to the channel of the person who authorised it.

Source code: github.com/jazzit01/mahaspark-engine
